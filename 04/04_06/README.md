# 04_06

Een gebruiker wil de dagen van de week invoeren in een array. De array heeft exact zeven plaatsen.

Vraag de gebruiker om de namen van alle zeven dagen van de week in te voeren. Sla deze op in een string-array.

Tonen: de eerste dag, de laatste dag en de dag op index 3.
