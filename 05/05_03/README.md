# 05_03

Maak een programma dat de gebruiker vraagt hoeveel getallen hij of zij wil invoeren. Vervolgens vraagt het programma die getallen één voor één en slaat ze op in een array. Tot slot berekent het programma het gemiddelde van alle ingevoerde getallen en toont het dit gemiddelde.
