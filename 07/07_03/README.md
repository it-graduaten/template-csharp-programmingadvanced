# 07_03

Maak een programma voor een winkel dat de totaalprijs berekent van producten in de winkelmand. De gebruiker voert de naam van het product, de prijs per stuk en het aantal in.

Het programma heeft een methode nodig die de drie waarden (productnaam, prijs per stuk, aantal) als parameters ontvangt en de totaalprijs teruggeeft (prijs per stuk vermenigvuldigd met aantal).

Het programma toont de totaalprijs aan de gebruiker.
