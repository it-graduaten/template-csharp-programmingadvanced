# 07_08

Maak een programma dat de gemiddelde score berekent van een lijst van scores. De gebruiker geeft eerst het aantal scores op dat hij wil invoeren. Daarna voert hij de scores in.

Het programma heeft een methode nodig die de lijst van scores als parameter ontvangt en de gemiddelde score teruggeeft (de som van alle scores gedeeld door het aantal scores).

Het programma toont de gemiddelde score aan de gebruiker.
