# 07_07

Maak een programma dat een bonnetje afdrukt van gekochte producten. De gebruiker voert de naam van het product, de prijs en de hoeveelheid in.

Het programma heeft een void methode nodig die de bonnetjesinformatie afdrukt. Deze methode ontvangt de productnaam, de prijs per stuk en de hoeveelheid als parameters.

De methode toont:
- De productnaam
- De prijs per stuk
- De hoeveelheid
- De totaalprijs (prijs per stuk vermenigvuldigd met hoeveelheid)
